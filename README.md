# Lab 03 - Creating a nextflow workflow for multiple samples

This lab is split into two parts:

- [**Part 1: Learn the DSL**](part1/README.md) — a small toy pipeline that
  teaches you Nextflow's record/channel syntax with zero stakes, before you
  touch any real tool.
- [**Part 2: Build & Operate the Pipeline**](PART2.md) — build the real
  bacterial-genome pipeline stage by stage, then run, debug, and configure
  it for real.

Start with Part 1.
